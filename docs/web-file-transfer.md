# XPScript web file transfer

(c) xpagedeveloper.com 2026

XPScript web routes can receive `multipart/form-data` uploads and return binary files through the shared web runtime used by Kestrel, FastCGI and CGI.

## Upload a file

```text
[Anonymous]
[Post]
Sub Upload()
    Dim file
    file = Request.FileFirst("upload")

    If file Is Nothing Then
        Response.StatusCode = 400
        Response.Write("Missing upload")
        Exit Sub
    End If

    Response.Write(file.FileName)
End Sub
```

Available request helpers include:

```text
Request.Form("name")
Request.FormFirst("name")
Request.Files()
Request.Files("fieldName")
Request.FileFirst("fieldName")
```

Uploaded files expose the normalized client filename, content type, length and binary content. Client-side paths such as `C:\fakepath\file.txt` are stripped before the filename is exposed to XPScript.

Multipart parsing is bounded. The runtime enforces limits for the complete request body, number of fields, number of files, individual file size and multipart part headers. Upload contents are kept in bounded memory in the initial implementation. No client-provided filename is used as a server filesystem path automatically.

## Return an uploaded file

```text
[Anonymous]
[Post]
Sub EchoUpload()
    Response.SendFile(Request.FileFirst("upload"))
End Sub
```

`Response.SendFile` writes a binary HTTP response and sets a safe `Content-Disposition` header. The filename is normalized before being returned.

## Return generated bytes

```text
[Anonymous]
[Get]
Sub Download()
    Dim data
    ' Build or obtain the byte array in application code.
    Response.SendFile(data, "report.bin", "application/octet-stream")
End Sub
```

Use the optional final argument to request inline disposition:

```text
Response.SendFile(data, "image.png", "image/png", True)
```

`Response.SendFile` deliberately does not accept an arbitrary filesystem path. This avoids turning untrusted input into unrestricted file reads. Application code that needs a site-local path must resolve it through the safe server path policy first.

## Transport limits

The transport request-body limit is applied before multipart parsing. Configure Kestrel, FastCGI or CGI body limits high enough for the intended upload size while keeping them bounded for the application. The multipart parser applies its own stricter field/file limits after the transport accepts the request.
