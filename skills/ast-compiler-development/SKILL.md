# AST compiler development

Use this workflow when adding support for an XP object or AST-only language feature.

## Object support contract

1. Add the object name and detection rules to `AstObjectSupportRegistry`.
2. Define the shared semantic symbols and signatures in the binder catalog.
3. Bind declared members with stable XPScript types and source spans.
4. Emit calls and member access through existing runtime APIs; do not duplicate runtime behavior.
5. Add the runtime surface in its own source file when the object needs generated support.
   For a native source-defined object, see `AstImageSupport`: derive compiler metadata from the existing runtime, preserve native overloads and static/instance distinctions, and share native type mappings across ordinary/protected locals, parameters and Static storage. Test ownership, returned references (including Variant), ByVal/ByRef and exceptional cleanup as well as API calls.
   For a required NuGet addon, register its version and runtime-use detection in `ApplicationDependencyCatalog`. The shared SDK backend adds selected package references and native assets, and generates `Third-party-license.txt` from the restored graph. Do not add a separate package-copy or license implementation for each object; verify both use and absence through `tests/GeneratedDependencyProbe` and the permanent Runtime FullTest.
6. Keep unsupported-object diagnostics explicit until the complete runtime contract exists.

## Verification

- Add a focused AST source fixture for success and unsupported cases.
- Run AST CLI compilation and execute the generated program when applicable.
- Run MCP/CLI validation for the same source and compare structured diagnostics.
- Run the relevant compiler probe and a normal `xpscript compile`.
- Commit and push only after build and tests pass.

## Design rule

Array parameter syntax retains rank/parenthesis/comma tokens and Optional/default metadata. Until physical lower bounds and shared whole-array ByRef storage are migrated together, keep explicit mapped XPS3001 guards in constructors, module procedures and ordinary methods; never silently resolve an array parameter as its scalar element. Pair CLI/MCP guard and invalid-rank/array-List diagnostics and run the lexer probe plus Language FullTest array signature harness.

List constructor signatures reuse ResolveParameterType with the existing symbol table/DeclaredType metadata; preserve ListOf<T> in registration, full/Optional signatures, body helpers and Parent.New scopes. Runtime parameter types must be Object for Lists, not the element's CLR type. Reuse typed StrongBox<LSList<T>> Optional cells and direct ByRef aliases, with no constructor copy-back path. Missing defaults are Nothing; factories/dependent defaults use shared conversion/lowering. Verify invariant scalar/user/native elements, erased generic overloads, replacement/default/body errors, ByVal child/base snapshots and borrowed image elements versus owned image fields in CLI/MCP and Language/Runtime FullTest. Keep ordinary class-method List signatures guarded and legacy mutation parity separate from replacement/ByRef/Optional capability.

Variant and shared native constructor signatures reuse DeclaredType, RuntimeObjectType, FunctionSymbol metadata, conversions and typed Optional cells. Preserve native semantic identity even when CLR representations coincide (HTTP Part/File), and retain exact ByRef types. Missing Variant defaults are typed Empty/null, not Nothing; native defaults are Nothing. Do not apply shared-reference borrowing to declared XPImage parameters: keep their guard until pre-base cloning/default cleanup is implemented. Test JSON/XML/CSV/spreadsheet/HTTP mutation/replacement, fresh/dependent defaults, Parent.New, aliases/errors, explicit HTTP disposal and borrowed Variant images versus owned image fields. Pair CLI/MCP errors and permanent FullTest markers; ordinary method signatures remain separate.

Constructor overloads reuse all registered FunctionSymbol signatures and shared conversion/address classification. Preserve selected metadata through New, Parent.New and Optional rewriting; emit signature-specific tags, body/default helpers and carriers so C# cannot re-resolve a call or collide on shortened signatures. Pair duplicate/ambiguous diagnostics in CLI/MCP and execute numeric, Nothing/specificity, arity, ByRef and base-forwarding regressions. XPImage/array signatures remain independent increments.

Optional ByRef Object/user-class constructors use compiler-internal ReferenceCell semantic shapes, emitted as StrongBox<T>, in shared OptionalCallLowering. Preserve T recursively through cells, arrays/Lists, ordinary/flat/error/Static declarations, reads, reference emission and List alias storage. Keep scalar omitted arrays unchanged. Typed initializer-free module storage uses existing SymbolTable metadata and shared field emission. Test fresh Nothing/New/dependent defaults, nested forwarding, Parent.New, duplicate array/List/module aliases, lower bounds, exact-type errors and image ownership; pair CLI/MCP and permanent FullTest markers. Do not silently change ordinary List procedure wrappers or array ForAll semantics. XPImage/array constructor signatures remain separate increments.

Optional ByVal Object/user-class constructor parameters reuse shared OptionalCallLowering with semantic locals/carriers, not heap ByRef cells. An absent default binds typed Nothing through existing conversion classification; never Activator.CreateInstance(Object). Preserve fresh New/dependent defaults, supplied snapshots, New/Parent.New/implicit bases, Optional caller rewriting and required ByRef writes on failure. Optional ByRef references use the typed cells described above; erased object arrays remain insufficient. Default-created user objects remain borrowed, including image fields; clean factory locals and the new instance's own image snapshots only. Pair CLI/MCP default type/name errors, update programming guidance and require AST_OPTIONAL_REFERENCE_CONSTRUCTORS_OK / AST_IMAGE_OPTIONAL_REFERENCE_CONSTRUCTORS_OK in permanent FullTest. Keep legacy omission parity separate.

Required ByRef Object/user-class constructors reuse FunctionSymbol modes, ValidateScalarReference and EmitReferenceArguments, not a second ref/copy-back engine. Keep semantic types in signatures/carriers; accept exact typed locals/parameters and real user fields, including Nothing-valued storage. Identity is mandatory: no class-to-Object or ancestry conversion for a ByRef slot. Preserve exact semantic element types in arrays, Lists and writable aliases; initializer-free typed module references are supported. Initialized compatibility storage, XPImage scalar references and array signatures remain deferred. Preserve live duplicate aliases, ordered once-only receivers, nested New/Parent.New and ByVal-child snapshots through scalar Optional defaults. Replacement persists on errors but never owns/Deletes old or replacement input objects/images; clean only the constructed instance's owned image fields/scopes. Pair CLI/MCP address/type/storage diagnostics and require AST_BYREF_REFERENCE_CONSTRUCTORS_OK / AST_IMAGE_BYREF_REFERENCE_CONSTRUCTORS_OK in permanent FullTest. Keep ordinary method/module signature migration separate and ByRef capability separate from valid ByVal legacy parity: normal simple reference ByRef currently prints 0 where AST prints 7.

Required ByVal Object/user-class constructor parameters use DeclaredType and the existing validated class dictionary, FunctionSymbol metadata and conversion rules. Gate precisely: reject scalar XPImage and unknown signatures; do not enable ordinary method object parameters. Preserve semantic C# types in full constructors, Optional signatures and carrier fields, not just body helpers, so required class references can precede scalar Optional parameters in both carrier paths. Reuse New/Parent.New binding for upcasts, Nothing, Variant conversions and diagnostics. References are shared snapshots, not owned objects: replacement stays local, mutation is shared even on errors, and failed construction/Delete clears own image snapshots, never the input object's fields. Test receiver order, defaults reading earlier members, Optional caller rewriting, Parent.New, borrowed versus owned images and paired CLI/MCP errors/deferrals. Require AST_REFERENCE_CONSTRUCTORS_OK / AST_IMAGE_REFERENCE_CONSTRUCTORS_OK in permanent Language/Runtime FullTest. Keep concrete-reference normal parity separate from broader AST Object/default/error capability.

Optional scalar ByRef constructors opt into OptionalCallLowering.Forward(heapBackedByRefDefaults: true). Allocate a fresh one-element typed array per omitted ByRef parameter, materialize its initializer as the declared scalar type before boxed array assignment (Byte zero must not become boxed Int32), and substitute the slot in later defaults and the final call. Reuse typed LSArrayRuntime.Reference emission for these calls; the interior managed reference keeps the array alive through the stack-only argument carrier. Never return a stack-local reference, use pointers or add copy-back. Supplied ByRef locations stay live; ordinary Optional procedure/accessor locals and ByVal-only constructor carriers stay unchanged. Test fresh explicit/implicit defaults, dependent mutations, generated names, scalar zeros, duplicate aliases, Parent.New/implicit bases, Optional caller rewriting, errors and image cleanup. Keep the Byte/freshness fixture early; pair mapped CLI/MCP diagnostics and require AST_OPTIONAL_BYREF_CONSTRUCTORS_OK / AST_IMAGE_OPTIONAL_BYREF_CONSTRUCTORS_OK in permanent FullTest. XPImage/array signatures remain deferred.

Mixed required scalar ByRef and trailing Optional ByVal constructors reuse OptionalCallLowering.Forward with a semantic return type and the existing bound emitter. Use a private typed ref struct holding managed reference fields for required ByRef arguments and value fields for other scalars. Keep it stack-only: never box it, store it on the instance, or return references to omitted stack default locals. Preserve the ByVal-only carrier path. Optional ByRef uses the heap-backed storage rule above. Test duplicate aliases, dependent/mutating defaults, supplied snapshots, Parent.New and image/default/body failures. Require AST_MIXED_CONSTRUCTORS_OK and AST_IMAGE_MIXED_CONSTRUCTORS_OK in permanent Language/Runtime FullTest; do not claim legacy ByRef or omitted-argument parity.

Required scalar ByRef constructors reuse FunctionSymbol.ByRefParameters, shared indexed-accessor ValidateScalarReference and EmitReferenceArguments. Carry modes through New, constructor signatures, Parent.New parameter scope/base initializers and body-helper calls. Exact-type addressable locals/parameters/fields/typed module scalars/array-List elements/ForAll aliases are managed references; never add constructor copy-back or consume an accessor result as storage. Validate bad addresses/types before backend compilation with paired CLI/MCP codes/lines. Required and Optional ByRef use the typed ref-struct carrier; preserve the ByVal-only carrier. Test duplicate/live aliases, later writes, receiver/index/tag order, bounds/missing tags, protected bodies, Optional caller rewriting, ByVal child snapshots and base/derived/argument image errors. Require AST_BYREF_CONSTRUCTORS_OK/AST_IMAGE_BYREF_CONSTRUCTORS_OK in Language/Runtime FullTest. Normal simple ByRef construction currently compiles but fails at runtime with a long.Value error; retain valid ByVal parity separately and do not claim ByRef legacy parity.

Optional scalar ByVal constructors record RequiredConstructorArgumentCount in the existing FunctionSymbol (preserve it through record copies/BoundNew rewriting). Validate trailing declaration shape through ValidateOptionalDeclarations, bind defaults with only earlier parameters and globals, and reuse OptionalCallLowering.Forward for sequential fresh locals. Generated short constructors bridge this/base initializers through a private scalar carrier; never substitute earlier defaults twice or evaluate them in instance scope. Validate even unused defaults and skip constructor defaults in the instance method/accessor default binder. Reuse non-virtual failed-construction cleanup; test caller preservation and image-owning default routines on success/failure. Pair position/type/name/arity/access/empty-slot diagnostics in CLI/MCP. Require AST_OPTIONAL_CONSTRUCTORS_OK and AST_IMAGE_OPTIONAL_CONSTRUCTORS_OK in Language/Runtime FullTest. Normal constructors currently require full arity despite Optional: keep full-arity parity distinct from AST omission capability. XPImage/array signatures stay deferred.

Derived constructors use the existing validated lineage scope, not a new hierarchy registry. Recognize a single first-statement Parent.New on existing call syntax and remove only that statement from the helper body; reject late/nested/duplicate/root calls. Bind its arguments through the shared New binder with only parameters and module declarations, then emit a real base initializer. Enforce base arity/conversions/private access as mapped CLI/MCP diagnostics before backend compilation. Keep ordinary derived methods/accessors deferred. Failed-construction cleanup must be a non-virtual per-class chain (own fields then base in finally) using AstImageScope.StoreField, never Delete or virtual dispatch from a partial object. Verify three levels, argument failures, each throwing body, inherited fields/locals, private shadowing, existing target preservation and no user destructor; keep simple normal/AST parity separate. Require AST_DERIVED_CONSTRUCTORS_OK and AST_IMAGE_DERIVED_CONSTRUCTORS_OK in existing Language/Runtime FullTest.

Root constructors reuse ConstructorDeclarationSyntax, BindProcedure and instance BoundMethodEmitter through a private helper. Register constructor FunctionSymbol metadata before member/body binding; preserve it in BoundNewExpression and OptionalCallLowering and emit canonical semantic class spelling. Plain scalar user-class Dim must bind a typed Nothing initializer, not manufacture a parameterless construction (also retain canonical storage casing). Support root Sub New with required or trailing Optional scalar ByRef/ByVal parameters; pair arity/type/private/body diagnostics in CLI/MCP and keep XPImage/array signatures explicitly deferred. Failed construction clears own typed image fields with existing AstImageScope.StoreField, never user Delete or a second ownership engine. Run run-ast-constructor.ps1 first, retain normal/AST parity separately from capability tests, and require AST_CONSTRUCTORS_OK/AST_IMAGE_CONSTRUCTORS_OK in Language/Runtime FullTest.

Derived destructor binding reuses the compilation unit's validated class dictionary, not another hierarchy registry. Import visible members in ancestor-to-current order so own private fields shadow ancestors; exclude inherited private fields/methods and use accessor visibility through Properties. Only constructor and destructor bodies bypass the existing derived-body guard. Emit override Delete wrappers with per-class/per-instance guards and finally-protected own-field cleanup plus base.Delete; do not synthesize base calls inside bound user statements, where Exit Sub/errors could skip them. Preserve standard finally error precedence. Verify three-level order, own private fields, inherited public property/helper/ByRef storage, Me/With, re-entry, repeated aliases, early exit and multiple throwing levels. Pair private-base and body diagnostics in CLI/MCP; retain ordinary derived-method XPS3001. Keep simple real normal/AST chain parity separate from richer AST error/alias/image capability fixtures.

Class destructor bodies reuse DestructorDeclarationSyntax (not SubDeclarationSyntax), BindProcedure and the shared instance BoundMethodEmitter in a private helper. Keep Delete's public virtual lifecycle wrapper separate: guard body execution per instance before entering it, and clear typed image fields in finally. Delete statements must clear named caller storage in finally too, preserving the original error path. Verify private helpers, Me, module storage, Exit Sub, protected/error-flow emission, inherited dispatch, re-entry and repeated aliases; do not infer LSRef alias invalidation or GC cleanup. Derived destructor bodies use the validated lineage scope; keep ordinary derived method/accessor bodies explicitly XPS3001. Pair parameter/duplicate/non-Sub/body diagnostics in CLI/MCP. Run run-ast-destructor.ps1 before broad suites, keep its small real normal/AST parity fixture, and require the throwing image-destructor fixture in Runtime FullTest.

Typed XPImage fields are cleared on explicit Delete through each generated class's virtual/override Delete chain. Reuse AstImageScope.StoreField(ref this.field, null) only for fields declared in that class, then invoke base.Delete; do not traverse inherited fields again or treat Variant references as owned images. Verify polymorphic deletion across multiple ancestry levels, private/public storage, alias visibility, source/instance isolation, Nothing, repeated deletion and active error-handler paths. Run image-field-delete early in the shared image harness and validate it via MCP; require AST_IMAGE_FIELD_DELETE_OK in Runtime FullTest. Do not infer finalizers, scope-exit cleanup or constructor forwarding from this subset.

XPImage Set uses snapshot-owned typed fields via the existing AstImageScope.StoreField helper. Clone before swapping/recycling storage; preserve old fields on clone failure and recycle on Nothing. Pass the field by ref to evaluate the receiver/address once before RHS evaluation. Track owning call/new/getter RHS values in the caller scope, without consuming borrowed local/field values. Preserve IsBorrowedImageSnapshot on final ByRef setter parameters and use Borrow/Replace in the same scope, not a second cleanup engine. ByVal clones once at actual accessor entry; suppress duplicate entry cloning in Optional forwarding. Verify original-source survival, shared explicit ByRef mutation, ByVal isolation, field snapshots, old-value cleanup, exceptions and receiver order. Run image-property-set and paired CLI/MCP type/mode diagnostics before broader suites; require both image harness markers in Language/Runtime FullTest. Explicit field clearing or Delete of the owner remains necessary: do not claim GC/scope-exit cleanup or Variant-field ownership.

XPImage Get factories reuse the existing procedure result slot, BoundMethodEmitter and AstImageScope. Never add another image copy-back/cleanup engine or silently clone getter results. Verify that returned images survive and that discarded locals, replaced results and results in a throwing accessor are recycled in ordinary/protected paths; retain scalar Optional/ByRef index semantics. Capture owning results in typed caller locals and explicitly Clone borrowed field/static images when retaining the original elsewhere. Image Set uses snapshot-owned typed fields as described above. Keep type/mode and getter permission/body/index diagnostics paired in CLI/MCP; run run-ast-image-get.ps1 first in Language/Runtime FullTest, including signature-only package/notices coverage. Do not close full image accessor/class lifecycle migration from Get support.

User-reference ancestry belongs to the compilation-local SymbolTable registry. Validate unknown bases and all cycles before any inherited-member traversal, then register class edges. Reuse ClassifyConversion in binders and default binding; never use process-global mutable inheritance state or authorize conversions merely because both CLR carriers are Object. Only declared scalar ancestry adds ReferenceUpcast, emitted with the target semantic C# type. Keep ByRef identity-only and arrays/Lists invariant. Preserve canonical base-class spelling. Test direct/transitive upward conversions, shared identity/mutation, setter-value snapshots, inherited fields, getter results and error exits; pair downcast/sibling/isolation/cycle/base diagnostics across CLI/MCP. Ordinary derived method/accessor bodies and complete lifecycle and advanced constructor signatures remain separate migration work.

Typed Object/user-class Get/Set reuses DeclaredType, property symbols and BoundMethodEmitter semantic signatures; never erase a concrete property/field/parameter/result to Object. Preserve PropertyAssignmentKind through bound members and Optional rewrites. The shared statement binder validates Set versus Let, scalar RHS rejection and concrete class compatibility. Set accepts call-shaped syntax only so the binder can resolve indexed accessors; ordinary function-call targets remain non-writable. Reference result slots start as Nothing. Index aliases are direct references, while incoming setter values are snapshot references, even with ByRef value parameters. Test typed chaining, optional and duplicate indexes, Nothing, permissions, With, instance state, RHS order and exceptional exits. Typed JSON/XML/CSV/spreadsheet/HTTP accessors reuse the native runtime mappings and shared reference semantics; generated script classes remain assembly-local so internal native signatures are legal. Other native-family accessors and ordinary derived method/accessor bodies remain explicit deferrals; XPImage follows its separate snapshot-storage contract. Cover the same fixtures and mapped diagnostics in AST CLI/MCP and the permanent Language FullTest.

Typed array/List indexed ByRef targets reuse shared storage and direct argument emission. LSArrayRuntime.Reference must validate exact element type, rank and every subscript before managed reference access; keep production-helper guard tests for rank 1–8, lower bounds, reference slots and scalar layouts. List cells must retain reference identity across assignment/dictionary growth; removal/recreation detaches old references, with no copy-back resurrection. Preserve typed ForAll aliases and System.Array dynamic storage in ordinary/flat/error-flow emitters. Do not add another indexed copy-back wrapper or silently change the existing ordinary List-call snapshot contract. Verify live updates from later argument evaluation, duplicate aliases, Get/Let RHS order and exceptional exits.

IndexedPropertySymbol now carries explicit ByRef index modes. Preserve them in both bound call emission and generated accessor wrapper signatures, sharing index argument emission for Get/Let. Require matching scalar types and writable locals/parameters/class fields or typed uninitialized Private/Public module variables. AstModuleFieldSupport shares module binding/storage metadata; VariableSymbol.HasTypedStorage excludes synthetic/dynamic globals. Mask headers instead of removing them to retain diagnostic spans. Carry IsFieldStorage provenance for qualified and implicit With class fields through binding and expression rewrites; never treat accessor-backed/native properties as addressable fields. Reject mismatched getter/setter modes and defer accessor-backed and initialized/reference-type module locations explicitly. Verify shared aliases and exceptional exits; never implement a second copy-back engine for field storage.

Scalar indexed properties reuse IndexedPropertySymbol/BoundIndexedPropertyExpression and the common accessor-body binder/emitter. Register independent read/write permissions, typed index signatures and canonical getter/setter targets. Evaluate receiver, indexes and incoming value once in order. ByVal/unmodified supplied indexes are snapshots. For trailing Optional indexes, carry RequiredArgumentCount and reuse OptionalCallLowering with a required setter-value tail; never treat the incoming value as an omittable index. Bind defaults in instance declaration scope with only earlier indexes, and evaluate them once at accessor entry, after supplied arguments/RHS. Give omitted ByRef values fresh locals and preserve supplied aliases. Match index types/modes/Optional positions across accessors. Accessor-backed ByRef locations and explicit empty slots remain deferred. Keep semantic local storage types shared across ordinary, flat and error-flow emission. Run indexed-optional-simple/runtime and mapped CLI/MCP negative fixtures before broader suites.

Scalar non-indexed class properties reuse the same procedure binder/emitter as class methods, with property wrappers calling bound Get/Let bodies. Register grouped property symbols with independent CanRead/CanWrite permissions; preserve private accessor visibility and canonical names, including implicit With. Parameterless Let uses the property name for the incoming value. Do not fabricate auto-property storage or infer complete lifecycle migration from this subset.

User class procedures use `AstClassMethodSupport`, shared `AstExperimentalCompiler.BindProcedure` control-flow validation and the instance mode of BoundMethodEmitter. Keep lexical class/member/parameter scopes separate, canonicalize declared member casing, omit private members externally and never scan class fields as module globals. Scope Program helper imports to generated user classes. Scalar typed bodies are verified; object/array/List signatures, Optional/Static and ordinary derived method/accessor bodies remain explicit XPS3001 deferrals. Do not close the parent class TODO until accessors, constructors, inheritance and destructor dispatch are migrated.

For Application, use `AstApplicationSupport`, source-derived native namespaces and the shared runtime/state proxies. Bootstrap command-line arguments before the bound Main; preserve Main call targets, Args snapshots and error 9. Use existing property targets/native conversions, reject read-only writes and New Application, and synchronize normal/MCP constructor/read-only diagnostics. Preserve OS credential/host guards, debugger activation and generated executable metadata through the existing packaging path. Include services only on actual use, without addons. Test registry only in isolated storage (Linux supports absolute XDG_CONFIG_HOME); never use real credentials for migration tests.

For HTTP use `AstHttpSupport` and the shared native metadata importer. Compose the real TLS validator and runtime exception from `CoreCompatibilityRuntimeSource`; never introduce an always-successful certificate callback or duplicate transport logic. Normal/AST JSON and authentication facades must delegate to existing helpers. Preserve whole-file legacy routing for async callbacks and UIForm. Test real local HTTP/TLS traffic, Strict/self-signed hostname/expiry rejection, SSRF restrictions, fractional timeouts, mapped diagnostics and absence of HTTP/TLS code when unused. Header dictionaries are dynamic Variant-indexed values, not integer-only arrays.

HTTP Get/Set accessors use those same native mappings and shared property semantics. Keep client Dispose explicit and shared across aliases; no auto-ownership or cloning. Preserve exact static XPHttpPart/XPHttpFile distinctions despite their common CLR representation. Reuse AstHttpRuntimeProbe's isolated endpoints for accessor traffic, multipart references and security/disposal checks; its --accessors-only mode runs the small regression first, while the full probe retains normal/AST parity and unused-code checks. Test signature-only native use and pair type/mode/read-only/object-index diagnostics in CLI/MCP. XPImage uses the separate snapshot-storage contract above.

For native XML, use `AstXmlSupport` with `AstNativeObjectSurface`, shared by CSV. The source-derived surface must retain inherited members and optional native arities. XML element-to-node conversion is a reference upcast, not a Variant coercion; ByRef still requires an exact type. Reuse `NativeXmlRuntimeSource` with its DTD/entity restrictions and resource limits. Test actual normal/AST execution, typed collections, reference semantics, implicit With calls and member names such as `.Parent` that must not be rewritten as class references. Verify unused/escape-only XML does not include the DOM or addon dependencies.

Object detection belongs in the registry. Binding, emission and runtime implementation remain separate layers so adding another XP object does not require expanding `AstExperimentalCompiler` with more object-specific regex logic.

For CSV, use `AstCsvSupport` and the existing `NativeCsvRuntimeSource`; do not introduce another CSV parser. Its conditional runtime selection is tested for actual use, strings/comments and escape-only programs. CSV uses shared managed references (not XPImage's ByVal cloning/disposal). Lower reference-replacing operations such as `FromBytes` through bound statements for both ordinary and `Call` syntax, preserving argument evaluation order. CSV/spreadsheet interop now uses the shared native helper through AST; helper-backed instance calls pass the receiver once via `ReceiverArgument`.

For spreadsheets, use `AstSpreadsheetSupport` and `SpreadsheetRuntimeSource.CoreCode`, adding the existing CSV interoperability source only on actual interop use. Do not add ClosedXML or another XLSX engine: the existing runtime uses framework ZIP/XML. Preserve external-workbook read-only/version guards, ZIP size/count limits, script-relative file paths and private-setter read-only properties. ByVal shares references; ByRef replaces them. Range.Values is native rank-one LSArray and must use shared bounds/index/ForAll handling. Compare existing demos through real normal and AST compilation, and test inferred interop results, malformed input, unused code and mapped MCP diagnostics before closing migration.
